Prima di eseguire il quickstart, installa gli strumenti elencati in questa pagina. Loyalty Hub gira in locale con Docker Compose e non richiede account su servizi esterni.

## Requisiti minimi di sistema

- **RAM libera:** almeno 6 GB. Lo stack completo usa 8 servizi Spring Boot più Kafka e Postgres.
- **Spazio disco:** circa 3 GB per immagini Docker e cache Maven.
- **Porte libere:** `3000` (web), `5432` (Postgres), `8081` - `8088` (microservizi), `8090` (Kafka UI), `9092` (Kafka).

## Verifica l'installazione

Esegui questi comandi e assicurati che restituiscano una versione compatibile.

```bash Verifica prerequisiti
# JDK 25 (accetta anche versioni 25.x)
java --version

# Docker e Compose plugin
docker --version
docker compose version

# Git
git --version
```

> **Nota:** Il repository include il Maven Wrapper (`./mvnw`). **Non installare Maven a mano**: usa sempre il wrapper per avere la versione corretta.

## Clona il repository

```bash
git clone https://github.com/peppe-ruv/loyalty_sys.git
cd loyalty_sys
```

## Cosa NON ti serve

- Un account Kafka, Neon, Render o Vercel. Servono solo per pubblicare la demo online (vedi [Deploy a costo zero](/docs_v2/operations/deploy-costo-zero)).
- Maven installato manualmente. Il wrapper `./mvnw` fa tutto.
- Configurazioni particolari di Postgres o Kafka. Il compose fornisce entrambi con impostazioni pronte.
