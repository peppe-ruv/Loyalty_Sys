# Mappa dei controlli ISO/IEC 27001:2022 Annex A

Documento previsto da `docs/18 §3.15` e ADR-044; la mappa completa dei 93 controlli, con responsabilità
**Prodotto / Adottante / Condivisa**, arriva con M12.6. Fino ad allora ogni fetta aggiunge qui i controlli che
tocca e l'evidenza che produce (`CLAUDE.md` regola 22).

| Controllo | Responsabilità | Funzione del prodotto | Evidenza | Fetta |
|---|---|---|---|---|
| A.5.15 Controllo degli accessi | Condivisa | `@RequiresRole` su ogni scrittura; ruoli dal claim `lh_roles` del token; più ruoli operatore ⇒ sola lettura (Q-365) | `OidcActorFilterTest`, `403 forbidden-role` sulle chiamate non ammesse | M8.2 |
| A.5.16 Gestione delle identità | Adottante (IdP), Prodotto (verifica) | identità solo dall'IdP OIDC nel profilo `enterprise`; `X-LH-Actor` ignorato | `OidcActorFilterTest` (header ignorato) | M8.2 |
| A.8.5 Autenticazione sicura | Condivisa | token verificato: firma dal JWKS, `iss`, `aud=hub`, scadenza; stesso `401` per ogni errore | `OidcActorFilterTest` (firma altrui, emittente, audience, scadenza) | M8.2 |
| A.8.9 Gestione della configurazione | Prodotto | il profilo `enterprise` non parte con identità insicura (`INSECURE_CONFIG`) | `IdentityGuardTest`, log di avvio | M8.2 |
| A.5.17 Informazioni di autenticazione | Prodotto (web), Adottante (IdP e segreti) | web (BFF): nessuna password gestita dal prodotto (login solo nell'IdP); token mai nel browser, cifrati AES-256-GCM lato server e legati alla sessione; segreto del client e chiave delle sessioni solo da variabile o `*_FILE`, mai nei log; il web in `enterprise` non parte con segreto corto o segnaposto, chiave non casuale, `http` fuori da `localhost` | `web/lib/auth/config.test.ts`, `crypto.test.ts`, `sessionStore.test.ts` (token non in chiaro, blob alterato scartato), `handlers.test.ts` (nessun token nella risposta), log di avvio `INSECURE_CONFIG` | M8.2 |
| A.8.5 Autenticazione sicura (web) | Condivisa | BFF client confidential: Authorization Code + PKCE S256, `state`, `nonce`, ID token validato; sessione nuova a ogni login (niente session fixation), cookie `__Host-` `HttpOnly` `Secure` `SameSite=Lax`, inattività 30 min e massimo 10 h; rinnovo con refresh token a rotazione, uno per sessione; CSRF con `Sec-Fetch-Site`, `Origin` e `X-LH-CSRF`; ritorno dopo il login solo su percorsi della stessa origine; back-channel logout con logout token firmato e anti-replay; sul portale il membro solo dal token | `web/lib/auth/oidc.test.ts`, `handlers.test.ts`, `refresh.test.ts`, `guards.test.ts` (open redirect, matrice CSRF, membro dal token), `logoutToken.test.ts`, `app/api/lh/[service]/[...path]/route.bff.test.ts` | M8.2 |
| A.8.26 Requisiti di sicurezza delle applicazioni | Prodotto | import file (BO-32): limite di dimensione e di righe, estensione e tipo dichiarato in allowlist, contenuto riconosciuto (UTF-8, niente binari, formato atteso), nome ripulito, file cancellato a fine lavoro; batch fino a 1000 eventi con tetto in byte (servizio e proxy) e limite di frequenza pesato sugli eventi; forma dell'envelope con lunghezze massime e senza NUL; una riga o un elemento velenoso non ferma il lavoro né produce un 500 | `ImportParserTest`, `EnvelopeLimitsTest`, `ImportsIT`, `ImportsRobustnessIT` (`IMPORT_*` 422, `BATCH_*`, `RATE_LIMITED`, righe velenose, lavoratori in gara) | M8.7 |
| A.8.12 Prevenzione della fuga di dati | Prodotto | rapporto dell'import (tabella e CSV) senza il soggetto dei non abbinati, letto dal monitor che l'anonimizzazione ripulisce; formule neutralizzate nel CSV; motivi delle righe non valide senza il valore letto | `ImportsIT` (rapporto), `ImportsRobustnessIT` (anonimizzazione), `ImportParserTest` (celle e motivi) | M8.7 |
| A.8.15 Registrazione | Prodotto | audit `CREATE` dell'import con attore, `sha256` e conteggi (mai il contenuto), `JOB` a fine lavoro, una voce per ogni riga riprovata | `ImportsIT` (voci su `lh.audit.v1`) | M8.7 |
| A.8.7 Protezione dal malware | Condivisa | file di import solo testo UTF-8 riconosciuto dal contenuto e mai eseguito né servito; antivirus sui file caricati in M8.10 (docs/18 §3.10 punto 8) | `ImportParserTest` (`IMPORT_NOT_TEXT`) | M8.7 (parziale) |
