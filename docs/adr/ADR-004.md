# ADR-004 — Sito cliente: Next.js con widget incorporabili · Customer site: Next.js with embeddable widgets

**Stato · Status**: approvata · accepted — 16 settembre 2026 · 16 September 2026

## Contesto · Context

Il programma deve vivere sia su un sito proprio con landing indicizzabili sia dentro un portale clienti e un'app
esistenti, senza duplicare la logica di presentazione.

**EN** — The programme must live both on its own site with indexable landing pages and inside an existing customer
portal and mobile app, without duplicating presentation logic.

## Decisione · Decision

Sito Next.js con rendering lato server e distribuzione via CDN; i componenti dell'area membro sono esportati come web
component incorporabili in qualunque pagina o app.

**EN** — A Next.js site with server-side rendering and CDN delivery; member-area components are exported as web
components embeddable in any page or app.

## Conseguenze · Consequences

Un runtime Node in più da gestire; in cambio una sola implementazione dell'area membro per tutti i punti di contatto.

**EN** — One more Node runtime to operate; in exchange, a single member-area implementation for every touchpoint.
