# ADR-004: Sito cliente: Next.js con widget embeddabili

Stato: approvata (16 settembre 2026)

## Contesto

Il loyalty deve vivere sia su un sito proprio (landing indicizzabili) sia dentro IrenYou e l'app.

## Decisione

Sito Next.js con rendering server e CDN; componenti esportati come web component.

## Conseguenze

Un runtime Node in più da gestire.
