# ADR-006: Tier per anno programma con discesa morbida

Stato: approvata (16 settembre 2026)

## Contesto

Le fasce premi si sbloccano per tier e il programma è annuale.

## Decisione

Upgrade immediato al superamento della soglia; a fine anno si scende al massimo di un livello.

## Conseguenze

Soglie da tarare sui dati reali; batch di fine anno simulabile in staging.
