# ADR-008 — Azioni interne nello stesso circuito · Internal actions in the same loop

**Stato · Status**: approvata · accepted — 16 settembre 2026 · 16 September 2026

## Contesto · Context

Partecipazioni, vincite, missioni completate e traguardi devono poter dare punti con le stesse regole delle azioni che
arrivano dai sistemi esterni.

**EN** — Contest entries, wins, completed missions and achievements must be able to grant points using the same rules as
actions arriving from external systems.

## Decisione · Decision

Concorsi, gamification e ciclo di vita del membro pubblicano azioni premianti interne sullo stesso topic e con la stessa
forma delle azioni esterne.

**EN** — Contests, gamification and the member lifecycle publish internal rewarding actions on the same topic and with
the same shape as external ones.

## Conseguenze · Consequences

Qualche secondo di latenza rispetto a un accredito diretto, accettato; in cambio una sola implementazione delle regole
e nessun percorso privilegiato.

**EN** — A few seconds of latency versus a direct credit, accepted; in exchange, one rules implementation and no
privileged path.
