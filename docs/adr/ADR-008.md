# ADR-008: Azioni premianti interne nello stesso circuito

Stato: approvata (16 settembre 2026)

## Contesto

Partecipazioni, vincite e missioni devono dare punti con le stesse regole delle azioni esterne.

## Decisione

Concorsi e programma pubblicano eventi interni sul topic delle azioni.

## Conseguenze

Latenza di secondi rispetto all'accredito diretto, accettata.
