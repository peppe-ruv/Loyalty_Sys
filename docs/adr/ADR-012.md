# ADR-012: Identità: IAM clienti Iren via OIDC

Stato: approvata (16 settembre 2026)

## Contesto

Il cliente entra già in IrenYou; il backoffice usa lo SSO aziendale.

## Decisione

Nessun archivio credenziali nel loyalty; il membro è identificato dal sub OIDC.

## Conseguenze

Dipendenza dalla disponibilità dello IAM, mitigata con cache e pagina di cortesia.
