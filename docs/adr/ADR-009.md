# ADR-009: Ingressi multipli, evento canonico unico

Stato: approvata (16 settembre 2026)

## Contesto

Le fonti sono eterogenee (REST, Kafka via middleware, file) e cambieranno nel tempo.

## Decisione

Adattatori per fonte che producono un CloudEvent con schema versionato; chiave di idempotenza obbligatoria; DLQ con riprocessamento.

## Conseguenze

Governance degli schemi da presidiare; il middleware è una fonte, non l'unica porta.
