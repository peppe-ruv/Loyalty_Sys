# ADR-001: Motore loyalty: core proprietario componibile

Stato: approvata (16 settembre 2026)

## Contesto

Il vincolo vendor neutral e l'instant win in Italia richiedono controllo su ledger, regole e ubicazione dati.

## Decisione

Core Java proprietario dietro la porta LoyaltyEngine; un motore SaaS resta un'alternativa sostituibile.

## Conseguenze

Più sviluppo iniziale; nessun canone per membro; perizia e residenza dati sotto controllo.
