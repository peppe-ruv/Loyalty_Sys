# ADR-001 — Motore loyalty: core proprietario componibile · Loyalty engine: composable in-house core

**Stato · Status**: approvata · accepted — 16 settembre 2026 · 16 September 2026

## Contesto · Context

Il vincolo vendor neutral, la necessità di far periziare il modulo concorsi e il controllo sulla residenza dei dati
richiedono il governo diretto di registro punti, regole e ubicazione dei dati.

**EN** — The vendor-neutral constraint, the need to have the contest module certified by a third party and control over
data residency all require direct ownership of the point ledger, the rules and where data lives.

## Decisione · Decision

Core Java proprietario dietro la porta `LoyaltyEngine`; un motore di terze parti resta un'alternativa sostituibile,
non una dipendenza.

**EN** — An in-house Java core behind the `LoyaltyEngine` port; a third-party engine remains a replaceable alternative,
not a dependency.

## Conseguenze · Consequences

Più sviluppo iniziale; nessun canone per membro; perizia tecnica e residenza dei dati sotto controllo; obbligo di
mantenere test sulle regole critiche.

**EN** — More up-front development; no per-member fee; technical certification and data residency under control; an
obligation to maintain tests on the critical rules.
