# ADR-003 — Linguaggio dei servizi di dominio: Java e Spring Boot · Domain service language: Java and Spring Boot

**Stato · Status**: approvata · accepted — 16 settembre 2026 · 16 September 2026

## Contesto · Context

Registro punti e concorsi richiedono transazioni solide e un'integrazione Kafka matura; il resto della piattaforma
(sito, backoffice, BFF) vive meglio nell'ecosistema TypeScript.

**EN** — The point ledger and the contests need solid transactions and mature Kafka integration; the rest of the
platform (site, back office, BFF) is better served by the TypeScript ecosystem.

## Decisione · Decision

Java (baseline 21, target 25 LTS) con Spring Boot per i servizi di dominio; TypeScript per sito, BFF e backoffice.
Il dominio resta codice puro, senza dipendenze dal framework.

**EN** — Java (baseline 21, target 25 LTS) with Spring Boot for the domain services; TypeScript for the site, BFF and
back office. The domain stays pure code, with no framework dependencies.

## Conseguenze · Consequences

Due ecosistemi da mantenere; immagini native per i servizi piccoli dove la memoria conta; dominio testabile senza
contesto Spring.

**EN** — Two ecosystems to maintain; native images for small services where memory matters; a domain testable without a
Spring context.
