# ADR-003: Linguaggio dei servizi di dominio: Java + Spring Boot

Stato: approvata (16 settembre 2026)

## Contesto

Ledger e concorsi richiedono transazioni solide e buona integrazione Kafka; le competenze Java sono in casa.

## Decisione

Java (baseline 21, target 25 LTS) con Spring Boot per i servizi di dominio; TypeScript per sito, BFF e CMS.

## Conseguenze

Immagini native per i servizi piccoli per contenere la memoria.
