## Base URL e porte

In ambiente demo locale ogni servizio risponde su `http://localhost:<porta>`.

| Servizio | Porta | Base URL |
| --- | --- | --- |
| Ingestion | 8081 | `http://localhost:8081` |
| Member | 8082 | `http://localhost:8082` |
| Campaign | 8083 | `http://localhost:8083` |
| Wallet | 8084 | `http://localhost:8084` |
| Reward | 8085 | `http://localhost:8085` |
| Gamification | 8086 | `http://localhost:8086` |
| Engagement | 8087 | `http://localhost:8087` |
| Insight | 8088 | `http://localhost:8088` |

> **Nota:** in produzione le porte sono nascoste dietro un API gateway. Chiedi al team infrastruttura il DNS e il prefisso di path assegnato al tuo ambiente.

## Come scegliere il servizio giusto

Parti dall'obiettivo, non dal dato.

- Vuoi **inviare un evento** (acquisto, visita, quiz)? Usa [Ingestion](/api/ingestion).
- Vuoi **leggere o aggiornare un cliente**? Usa [Member](/api/member).
- Vuoi **creare o simulare una campagna**? Usa [Campaign](/api/campaign).
- Vuoi **consultare il saldo punti o il tier**? Usa [Wallet](/api/wallet).
- Vuoi **gestire il catalogo premi o riscattare un coupon**? Usa [Reward](/api/reward).
- Vuoi **gestire concorsi, obiettivi o classifiche**? Usa [Gamification](/api/gamification).
- Vuoi **inviare notifiche o gestire template**? Usa [Engagement](/api/engagement).
- Vuoi **KPI, streaming eventi o DLQ**? Usa [Insight](/api/insight).
