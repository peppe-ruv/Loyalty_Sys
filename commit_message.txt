refactor(campaign): builder SQL con colonne da allowlist [F2-SEC-10, ADR-042, M8.10]

Sostituisce le query SQL dinamiche nei repository del servizio campagne con il
builder condiviso SqlWhere/SqlOrder. I test aggiuntivi garantiscono che
la funzionalità di ricerca per status, actionType e query 'q' sia corretta.

Note per il revisore:
Il builder `SqlWhere` attuale non supporta nativamente l'operatore SQL
`ANY(array)`. Come soluzione temporanea e sicura per la query `actionType`, il parametro viene ora passato al contesto
via stringa pre-costruita che viene accodata ai controlli di `SqlWhere`, utilizzando
il binding JDBC nativo per prevenire rischi di SQL injection in modo equivalente alla soluzione
originale.

Inoltre, il comportamento dell'operatore `%` e `_` nel parametro `q` è stato testato, confermando
l'escape adeguato garantito da `ilike`.

- `CampaignRepository` and `EvaluationLogRepository` search refactored to `SqlWhere`/`SqlOrder`
- Added tests asserting filtering, ordering, wildcard literal escaping and SQL injection protection.
